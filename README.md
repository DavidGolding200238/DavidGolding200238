## About

I finished my UX/UI degree and I am in my last year of development. I work across both sides: research and screens on one end, working apps and sites on the other.

What I have actually shipped:

- **Doomagotchi** — Android app. A digital pet that gets sick and dies if you doomscroll. Expo / React Native, Firebase, real device usage tracking.
- **GamerGrid** — Full-stack games platform. React, Express, MySQL, AWS. Accounts, communities, game discovery.
- **ThunderStats** — React dashboard for comparing War Thunder vehicle data.
- **Billionaires** — E-commerce frontend with a designed product flow.
